# محدودیت‌ها و راه جایگزین (T10.4)

منبع داده: [`src/limits/catalog.ts`](../src/limits/catalog.ts) — همین فهرست در `siavash limits`، ابزار `get_limits` (برای LLM و MCP) و تب «محدودیت‌ها»ی پنل وب نمایش داده می‌شود. هر مورد یک «راه جایگزین» دارد.

| دسته | محدودیت | راه جایگزین سیاوش |
|---|---|---|
| فقط انسانی | شارژ حساب لیارا | خواندن موجودی و هزینهٔ ماهانه قبل از ساخت/تغییر پلن، لینک شارژ، صبر و چک دوباره |
| فقط انسانی | خرید دامنه | وصل کردن دامنه به اپ و گفتن رکوردهای لازم |
| فقط انسانی | DNS نزد ثبت‌کننده (ایرنیک) | نمایش رکورد دقیق + بررسی با DNS lookup، سپس SSL |
| شکاف API | جزئیات اپ | list + filter با کش ۵ ثانیه |
| شکاف API | فهرست/وضعیت release | ledger محلی deployها + رویدادها و لاگ build |
| شکاف API | rollback | redeploy آخرین سورس سالم از ledger (با تأیید) |
| شکاف API | خواندن env | `liara env:list`؛ فقط نام‌ها نمایش داده می‌شوند |
| شکاف API | قیمت پلن‌ها | `liara plan:list` یا کاتالوگ محلی تاریخ‌دار |
| شکاف API | زمان پاسخ routeها (APM) | پروب HTTP خود سیاوش |
| رفتار نامعلوم | replace/merge در update-envs | read → merge → write؛ حذف با `env:unset` |
| رفتار نامعلوم | پایان restart/scale (فقط «accepted») | poll وضعیت واقعی + پروب آدرس |
| رفتار نامعلوم | واحد متریک‌ها | مقایسه با سقف پلن و اعلام عدم قطعیت |
| rate limit | 429 | retry با backoff و Retry-After، بودجهٔ درخواست جلسه، loop breaker |
| LLM | خطای مدل | هر فرضیه باید شاهد داشته باشد؛ الگوهای شناخته‌شده بدون LLM |
| LLM | محرمانگی لاگ | redact قبل از ارسال؛ فقط خوشه‌های خطای ناشناخته |
| عامل | پایش ۲۴/۷ ندارد | بررسی به درخواست / `watch` کوتاه؛ پیشنهاد cron با `siavash health` |
| عامل | تشخیص قطعی نیست | رتبه‌بندی با اطمینان و شاهد + verify قبل/بعد |
| عامل | عملیات حساس خودکار نیست (عمداً) | R0 خودکار؛ R1/R2 تأیید؛ R3 تایپ نام اپ؛ همه در audit |

سؤال‌های باز API: [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md).
